## Como usar (3 passos)

1. **Pessoas** — quem está em cada time  
2. **Tarefas** — o que fazer (arraste para Concluído)  
3. **Hoje** — lista do que fazer agora  

**Código** = cole o commit para a % do projeto subir.  
Pontuação por **feitos** (tarefas/commits), não por horas.
